# Итоговый практикум: лендинг на Bootstrap с JavaScript

Одностраничный сайт на основе бесплатного шаблона [Start Bootstrap Grayscale](https://startbootstrap.com/theme/grayscale/) (лицензия MIT). Шаблон доработан: добавлены собственные стили и скрипт на JavaScript.

## Просмотр

- Сайт: https://milkkiis.github.io/itogi_java/
- Локально: откройте файл `docs/index.html` в браузере.

## Что сделано

### Стили (docs/css/custom.css)

- повышена читаемость текста и ссылок на тёмном и светлом фоне;
- плавная прокрутка по якорным ссылкам;
- анимация появления секций (класс `reveal`);
- полоса прогресса прокрутки;
- ночной режим: тёмные секции Projects и Contact, цвета меню при прокрутке;
- оформление ошибки в форме подписки.

### Скрипт (docs/js/custom.js)

- обработчик события `scroll`: полоса прогресса, процент прокрутки в подвале, показ кнопки «наверх»;
- кнопка «наверх» через `window.scroll()`;
- анимация появления секций через `IntersectionObserver`;
- смена цвета заголовка по клику (изменение стилей через DOM);
- переключение ночного режима с сохранением выбора в `localStorage`;
- проверка email в форме подписки с сообщениями об ошибке и успехе.

Использованы методы `addEventListener`, `getElementById`, `querySelectorAll`, `classList`, `style`, `textContent`.

### Разметка (docs/index.html)

В разметку шаблона добавлены идентификаторы и классы для скрипта, полоса прогресса, счётчик прокрутки, кнопки «Night mode» и «наверх», подключены `custom.css` и `custom.js`. Скрипт SB Forms удалён, форму проверяет собственный код.

## Структура проекта

- `docs/index.html` — главная страница;
- `docs/css/styles.css` — стили шаблона;
- `docs/css/custom.css` — мои стили;
- `docs/js/scripts.js` — скрипт шаблона;
- `docs/js/custom.js` — мой скрипт;
- `docs/assets/` — иконка и изображения шаблона.
