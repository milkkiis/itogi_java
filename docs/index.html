Grayscale

Бесплатная адаптивная одностраничная тема на Bootstrap от Start Bootstrap.

Начать

Создано на Bootstrap 5

Grayscale — бесплатная тема на Bootstrap от Start Bootstrap. Вы можете скачать шаблон на странице предпросмотра. Тема распространяется с открытым исходным кодом, её можно использовать для любых целей, личных и коммерческих.

Побережье

Grayscale имеет открытый код и лицензию MIT. Это значит, что тему можно использовать в любом проекте, в том числе коммерческом. Скачайте её, настройте и опубликуйте свой сайт.
